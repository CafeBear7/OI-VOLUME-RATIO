#標的市場 近月 OI（張）5 日均量（張） OI／量比（刻度 0–200%）日變化
計算方式：OI／量比 =（近月未沖銷契約數 × 每口股數）÷ 近 5 個交易日平均成交股數；每口股數依期交所公告（一般 2,000 股、小型 100 股、ETF 10,000 單位、調整型契約依調整後股數）。表中張數 = 股數 ÷ 1,000。
資料來源：臺灣期貨交易所 OpenAPI、臺灣證券交易所 OpenAPI、證券櫃檯買賣中心 OpenAPI。每日盤後由 GitHub Actions 更新。本頁僅供參考，請以官方公告為準。
